전사 분석 실험실 · MOCK 기본 / 로컬 STT 선택

기본 MOCK 입력은 실제 통화 녹음, 마이크, STT가 아닙니다. 본인이 사용 권한을 가진 허구의 테스트 발화만 입력하세요. 개인 연락처·계좌번호·비밀번호는 입력하지 마세요. 합성 대본과 혼합되지 않으며 새 사건에서 시작해야 합니다.

실제 목소리가 아닌 합성 톤의 SHA-256과 미리 작성한 테스트 문장을 매칭합니다. 음성 내용 인식, 화자 식별, 외부 전송을 수행하지 않습니다.

선택 기능: 로컬 Whisper 음성인식 (기본 비활성)

로컬 STT 준비 상태 확인 중입니다.

본인이 사용 권한을 가진 10초 이내 WAV PCM16 모노 16kHz 파일만 선택하세요. 이 기능은 서버의 로컬 Whisper 모델이 설정된 경우에만 동작하며, 파일을 임시 디스크에 기록했다가 처리 후 삭제합니다. 외부 API와 실제 통화에는 연결하지 않습니다. 인식된 텍스트는 화자 구분이 없는 초안입니다.

v1.34 — 로컬 WAV 재생 / 검토형 STT (기본 40초, 동의 시 120초)

사용 권한이 있는 기본 40초 이하, 연구 모드 최대 120초의 16kHz·PCM16·모노 WAV를 내 브라우저에서 재생합니다. MP4 또는 외부 URL 자동 추출은 제공하지 않습니다. 매 구간의 음성 분석은 별도 명시적 동의가 있어야 서버의 로컬 STT로 전송하며, 초안을 직접 확인해야 위험 근거가 됩니다. 실제 전화 감지가 아닙니다.

기본 40초/8구간. 연구 모드는 새 정상 가족 연락 사건에서 음성 입력 전에만 활성화할 수 있습니다.

WAV를 선택하면 브라우저에서만 재생할 수 있습니다. 모델 미설치 시 분석은 비활성화됩니다.

오디오 자동 분석, 신원 식별, 카드 잠금, 송금 보류는 이루어지지 않습니다.
